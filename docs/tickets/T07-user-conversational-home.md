## 1. 目标

交付用户登录后的默认落地页：左侧信息侧边栏（用户信息 / 五大技能入口 / 会话记录）+ 中间自然语言与图片组合输入卡 + 底部功能 pill Tab，作为所有功能的分发中枢。

## 2. 背景与范围

**在范围内**
- `workspace.html` 视图 A 全部静态结构与样式
- 会话记录列表：新建 / 切换 / 删除，切换后回填历史参数
- 输入卡：图片上传入口 + textarea + Agent 模式开关 + 发送按钮
- 5 个功能 pill Tab；四大未开通功能点击 toast"该功能即将上线"
- 视图切换骨架（首页 ⇄ 套图子页面，无刷新）

**明确排除**
- 四大功能的实际实现 → v2.0 悬空
- 易点余额 / 会员体系的真实计费 → 静态展示

## 3. 前置依赖

## 5. 关键实现

```js
// 视图切换：内部状态驱动，不跳转页面
function switchView(view) {
  state.view = view;
  el.homeView.classList.toggle('hidden', view !== 'home');
  el.shotView.classList.toggle('hidden', view !== 'shot');
  sidebar.classList.toggle('collapsed', view === 'shot'); // 侧栏收缩至 124px
}
```

**状态保持**：切换视图不重新鉴权，`activeSessionId` 跨视图保持，返回首页时输入卡保留已上传缩略图。

## 7. 验收标准（AC）

1. 登录后默认进入首页，未登录访问自动跳 `index.html`。
2. 新建会话 → 列表新增且自动选中 → 进入视图 B。
3. 点击历史会话 → 正确回填该会话的原图、补充信息、组图开关、风格与结果。
4. 删除会话有二次确认，删除后列表同步刷新。
5. 四大未开通功能点击均 toast，且不切换视图。
6. 未上传图片时发送按钮禁用并给出提示。
7. 1280px 宽度下布局不塌陷，侧边栏独立滚动。

## 9. 风险与决策

| 决策 | 原因 |
|------|------|
| SPA 单页多态而非多 HTML | 套图子页面与首页共享会话上下文，避免跳转丢失状态 |
| 四功能保留 UI 而非隐藏 | 明确传达产品规划；同时诚实标注未开通 |
| 删除用原生 confirm | 控制实现成本，v1.1 可换自定义弹窗 |
