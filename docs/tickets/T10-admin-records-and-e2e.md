## 5. 关键实现

```js
// 状态三态映射（前端展示层统一收敛）
const STATUS_MAP = {
  success: { text: '成功',   color: '#10B981' },
  pending: { text: '进行中', color: '#3B82F6' },
  generating: { text: '进行中', color: '#3B82F6' },
  failed:  { text: '失败',   color: '#EF4444' }
};

// 进行中轮询：仅当页内存在非终态记录时才起定时器
if (rows.some(r => !['success','failed'].includes(r.status))) startPolling(5000);
```

**轮询收敛**：页面切换或全部记录进入终态时清除定时器，避免后台空转。

## 7. 验收标准（AC）

1. 生图记录七字段齐全，用户名与会话名正确 JOIN 出来，非空。
2. 生成时间精确到分钟，格式 `YYYY-MM-DD HH:mm`。
3. 生图类型统一显示"生成套图"标签。
4. 三态颜色与文案正确；进行中记录 5s 后自动刷新为终态。
5. 缩略图点击弹出大图，遮罩与 ✕ 均可关闭；失败记录显示 "-"。
6. 端到端：用户侧生成 3 张后，管理端能在 5 秒内看到对应 3 条记录。
7. 用户反馈视图显示占位空态，不发起任何请求。
