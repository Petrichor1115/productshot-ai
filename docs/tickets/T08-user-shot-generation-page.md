## 1. 目标

交付套图生成的专属操作页：三列式布局，中间完成四层参数配置，右侧完成大图预览、全部下载与三张缩略图展示，并对生成中 / 失败 / 成功给出清晰状态反馈。

## 2. 背景与范围

**在范围内**
- 三列布局：侧栏收缩至 124px + 配置区 360px + 结果区 flex:1
- 配置四层：主图上传（≤9 张）、补充信息（500 字上限）、组图内容三项开关、四风格选择
- 结果区：大图预览 + 全部下载 + 三张缩略图（含加载 / 失败 / 待生成态）
- 与 `/api/generate` 对接，展示"已生成 N 张 · 用时 Xs"

**明确排除**
- 尺寸比例扩展（当前固定 1:1）→ 预留扩展位
- 打包 ZIP 下载（当前依次触发单张下载）→ v1.1
- 单张重新生成 → 悬空

## 5. 关键实现

```js
// 三态渲染：单张失败不影响其余
function renderThumbs(results) {
  results.forEach(r => {
    const el = thumbMap[r.shot_type];
    if (r.status === 'success')      el.classList.add('is-success');
    else if (r.status === 'failed')  el.classList.add('is-failed');
    else                             el.classList.add('is-pending');
  });
}
```

**失败隔离的前端对应**：后端 T06 保证单张失败仍返回其余结果，前端按 `status` 逐张渲染，不做整体报错弹窗。

## 7. 验收标准（AC）

1. 上传 9 张后缩略图横向滚动正常，单张删除与"重选"生效。
2. 补充信息输入达 500 字时计数正确且不超上限。
3. 取消勾选"使用场景"后，生成结果只有 2 张且不产生场景记录。
4. 切换风格后生成的图风格明显不同。
5. 生成过程中按钮禁用、缩略图显示 loading；完成后显示大图与耗时。
6. 单张失败时该缩略图标红，其余两张正常展示与下载。
7. 点击缩略图可切换大图预览；"全部下载"可下载全部成功图片。
8. 未上传主图时"立即生成"禁用，hover 提示"请先上传主图"。
