# 火山引擎方舟（Ark）大模型平台 — 打通文档

> 记录本项目如何接通火山引擎方舟的两个核心能力：**文生文 / 多模态理解**（豆包 C 2.1 Lite）与 **文生图**（豆包 C Dream 5.0）。
> 包含 API Key 获取、模型 ID、请求示例、代码位置与验证方法。本文档即项目 `src/services/ai/volcClient.js` 的实现依据。

---

## 一、平台接入信息

| 项 | 值 |
|----|----|
| 控制台地址 | https://console.volcengine.com/ark |
| API Base URL | `https://ark.cn-beijing.volces.com/api/v3` |
| 鉴权方式 | API Key（Header `Authorization: Bearer <API_KEY>`） |

### 1.1 获取 API Key

1. 登录 [火山引擎方舟控制台](https://console.volcengine.com/ark)
2. 左侧菜单 →「API Key 管理」
3. 点击「创建 API Key」，复制保存（**仅显示一次**）

### 1.2 模型 ID

| 能力 | 模型 | 实测可用模型 ID |
|------|------|-----------------|
| 文生文 / 多模态理解 | 豆包 C 2.1 Lite | `doubao-seed-2-1-lite-260915` |
| 文生图 | 豆包 C Dream 5.0 Pro | `doubao-seedream-5-0-pro-260628` |

> 模型 ID 以控制台「模型广场 / 在线推理」中显示的为准；也可创建推理接入点（Endpoint），用 Endpoint ID
> （形如 `ep-20250101000000-xxxxx`）替代模型 ID，效果相同。开发阶段直接用模型 ID 更简单。
>
> **注意**：需要在控制台关闭「安全体验模式」，否则会触发调用限额。原计划的 `doubao-seedream-5-0-lite-260128`
> 已下线，实测账号可用的图片模型为 5.0 Pro。

## 二、项目内配置

配置写在项目根目录 `.env`（由 `.env.example` 复制而来，`.env` 已被 `.gitignore` 排除）：

```env
# 火山引擎方舟（可选）——
# 配置后自动切换到豆包视觉理解 + Seedream 真实出图；留空则降级为本地确定性渲染
ARK_API_KEY=your_api_key_here
ARK_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
ARK_VISION_MODEL=doubao-seed-2-1-lite-260915
ARK_IMAGE_MODEL=doubao-seedream-5-0-pro-260628
ARK_TIMEOUT_MS=30000
```

| 变量 | 对应代码 | 说明 |
|------|----------|------|
| `ARK_API_KEY` | `config.volc.apiKey` | 为空时 `config.volc.enabled = false`，走本地降级 |
| `ARK_BASE_URL` | `config.volc.baseUrl` | 方舟 API 域名 |
| `ARK_VISION_MODEL` | `config.volc.visionModel` | 视觉理解模型 |
| `ARK_IMAGE_MODEL` | `config.volc.imageModel` | 图像生成模型 |
| `ARK_TIMEOUT_MS` | `config.volc.timeoutMs` | 单次上游调用超时（毫秒） |

> 代码里的默认模型名是保守占位值，**配置真实 Key 时请按控制台已开通的模型 ID 填写**，否则会返回 404 model not found。

## 三、文生文接口（豆包 C 2.1 Lite）

### 3.1 接口信息

- **URL**：`POST https://ark.cn-beijing.volces.com/api/v3/chat/completions`
- **Header**：`Authorization: Bearer <API_KEY>`、`Content-Type: application/json`

### 3.2 请求示例

```json
{
  "model": "doubao-seed-2-1-lite-260915",
  "messages": [
    { "role": "user", "content": "用一句话介绍你自己" }
  ],
  "temperature": 0.7,
  "max_tokens": 2048
}
```

### 3.3 响应示例

```json
{
  "id": "chatcmpl-xxxxxxxx",
  "object": "chat.completion",
  "created": 1730000000,
  "model": "doubao-seed-2-1-lite-260915",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "我是豆包，由字节跳动开发的人工智能助手，可以帮你回答问题、生成文本等。"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": { "prompt_tokens": 12, "completion_tokens": 25, "total_tokens": 37 }
}
```

### 3.4 项目内调用

```javascript
const { analyzeProduct } = require('./src/services/ai/volcClient');

// 传入本地图片绝对路径 + 用户补充信息，返回 { name, category, sellingPoints[] }
const vision = await analyzeProduct('uploads/xxx.png', '品牌：SoundFree；卖点：主动降噪');
```

## 四、文生图接口（豆包 C Dream 5.0）

### 4.1 接口信息

- **URL**：`POST https://ark.cn-beijing.volces.com/api/v3/images/generations`
- **Header**：`Authorization: Bearer <API_KEY>`、`Content-Type: application/json`

### 4.2 请求示例

```json
{
  "model": "doubao-seedream-5-0-pro-260628",
  "prompt": "电商产品主图，无线蓝牙耳机，简约白底，soft shadow，主体居中，商业摄影质感",
  "size": "1024x1024",
  "response_format": "b64_json",
  "watermark": false,
  "image": "data:image/png;base64,<原图 Base64>"
}
```

> **尺寸限制**：Seedream 5.0 系列有最低总像素要求（Lite 约 3,686,400，Pro 按控制台说明）。本项目出图统一使用
> `1024x1024`，若上游返回尺寸错误，可在 `src/services/ai/imageGenerator.js` 中调整 `size`。
>
> **图生图**：把参考图以 `data:image/...;base64,...` 形式放入 `image` 字段；不传即文生图。

### 4.3 响应示例

```json
{
  "created": 1730000000,
  "data": [
    { "b64_json": "<Base64 图片数据>" }
  ]
}
```

### 4.4 项目内调用

```javascript
const { generateImage } = require('./src/services/ai/volcClient');

const buffer = await generateImage({
  prompt: '电商产品主图，无线蓝牙耳机，简约白底',
  referenceImageAbsPath: 'uploads/xxx.png',
  size: '1024x1024',
});
// buffer 为 PNG 二进制，由 imageGenerator 落盘到 uploads/gen-xxx.png
```

## 五、多模态图片理解（豆包 C 2.1 Lite）

豆包 C 2.1 Lite 天生支持图文混合输入，本项目用它从商品原图提炼名称、类目与 3 条卖点：

```json
{
  "model": "doubao-seed-2-1-lite-260915",
  "messages": [
    { "role": "system", "content": [{ "type": "text", "text": "你是资深电商商品分析师……只输出 JSON" }] },
    {
      "role": "user",
      "content": [
        { "type": "image_url", "image_url": { "url": "data:image/png;base64,<原图 Base64>" } },
        { "type": "text", "text": "请分析这张商品图，输出 JSON：{name, category, sellingPoints}" }
      ]
    }
  ],
  "temperature": 0.4
}
```

提示词模板存放在 `skills/product-shot-template.json` 的 `vision_extraction` 节点，修改模板即可调整识别口径。

## 六、验证方法

### 6.1 端到端验证（推荐）

```bash
# 1. 配置 Key
copy .env.example .env        # 填入 ARK_API_KEY
# 2. 启动服务
npm start                     # 日志中「出图模式：volc-ark」表示已启用真实出图
# 3. 冒烟测试
npm run test:smoke
```

`GET /api/health` 返回的 `data.gen_mode` 会明示当前模式（`volc-ark` / `local-mock`）。

### 6.2 直接验证上游接口（curl）

```bash
curl -X POST https://ark.cn-beijing.volces.com/api/v3/chat/completions \
  -H "Authorization: Bearer $ARK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"doubao-seed-2-1-lite-260915","messages":[{"role":"user","content":"用一句话介绍你自己"}]}'
```

### 6.3 降级验证

删除或清空 `.env` 中的 `ARK_API_KEY` 后重启，日志显示 `local-mock`，此时上传 → 生成链路仍可完整走通，
但产物是 SVG 版式图（不是真实 AI 出图），`/api/health` 同样会如实返回模式。

## 七、常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| `401 Unauthorized` | API Key 错误或过期 | 检查 `.env` 中 `ARK_API_KEY` |
| `404 model not found` | 模型 ID 错误或未开通 | 到控制台模型列表确认最新模型 ID |
| `size 参数无效` | 图片尺寸低于最低像素要求 | 改用 `1024x1024` 或控制台推荐档位 |
| `额度不足` | 账户余额不足 | 到控制台充值或领取免费额度 |
| 出图结果仍是 SVG | `.env` 没生效 / Key 为空 / 上游失败降级 | 检查启动日志的出图模式，查看 `logger.warn` 中的上游报错 |
| 上传图片被判无效 | 像素面积过小 | 使用 ≥960×960 的原图 |
