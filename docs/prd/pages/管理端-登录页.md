## 4. 核心功能

### 4.1 管理员登录
- 默认账号：`admin` / `admin123`（后端首次启动自动创建）
- 调用 `POST /api/auth/login`
- 登录成功后后端返回 role=admin
- 前端校验 role，非 admin 不允许进入
- 成功：保存 token，跳转 admin-dashboard.html
- 失败：显示错误提示

### 4.2 鉴权校验
- 登录后所有管理端 API 调用需携带管理员 token
- 后端校验 role=admin，否则返回 403

---

## 5. 交互流程

```
输入账号密码 → 点击登录
  → 前端非空校验
    → 空：提示"请输入账号和密码"
    → 非空：调用登录 API
      → 成功且 role=admin：存 token → 跳转 admin-dashboard.html
      → 成功但 role≠admin：提示"无管理员权限"
      → 失败：提示"账号或密码错误"
```

---

## 6. 校验规则

| 字段 | 规则 | 提示 |
|------|------|------|
| 账号 | 非空 | "请输入管理员账号" |
| 密码 | 非空 | "请输入密码" |
