# 子页面 PRD — 管理端主控台（侧边导航版）

> 所属产品：AI 商品套图生成器  
> 页面文件：`public/admin-dashboard.html`（单页多视图 SPA）  
> 关联 JS：`public/js/admin.js`  
> 版本：v2.1（新增左侧固定导航栏，扩展为 4 个菜单页）

---

## 1. 页面定位

管理员统一工作入口。采用「**左侧固定导航栏 + 右侧内容区**」布局，通过导航菜单在 4 个功能视图间无刷新切换：

| 菜单项 | 视图定位 |
|--------|----------|
| 数据看板 | 核心统计指标总览（默认首页） |
| 会话记录 | 全平台用户会话列表 |
| 生图记录 | 全平台图片生成记录明细列表 |
| 用户反馈 | 用户反馈入口（v2.1 预留） |

## 3. 左侧固定导航栏组件

### 3.1 菜单项配置

菜单项**按以下固定顺序**自上而下排列，每项包含「图标 + 文字」：

| 顺序 | 菜单项 | 图标 | 目标视图 | URL hash |
|------|--------|------|----------|----------|
| 1 | 数据看板 | 📊 | 统计卡片视图 | `#/dashboard` |
| 2 | 会话记录 | 💬 | 会话列表视图 | `#sessions` |
| 3 | 生图记录 | 🖼️ | 生图记录列表视图 | `#records` |
| 4 | 用户反馈 | 💌 | 反馈占位视图 | `#feedback` |

### 3.2 菜单项样式

| 状态 | 样式 |
|------|------|
| 默认 | 高 48px，左右内边距 20px，图标 20px + 文字 14px，文字色 `#4B5563`，图标与文字间距 12px |
| **hover 高亮** | 背景 `#EEF2FF`，文字色 `#2563EB`，光标 pointer，过渡 150ms |
| 选中（当前视图） | 背景 `#E0E7FF`，文字色 `#2563EB` 加粗 600，**左侧 3px 竖条** `#2563EB` |
| 禁用/预留（用户反馈） | 正常展示可点击，进入后显示占位空状态 |

### 3.3 导航交互逻辑

```
点击菜单项
  → 更新 URL hash（如 #/records），不刷新页面
  → 切换右侧内容区视图（显示目标视图，隐藏其余视图）
  → 更新菜单选中态（左侧竖条 + 高亮背景）
  → 按需触发该视图的数据加载（首次进入或刷新时）

浏览器前进/后退
  → 监听 hashchange 事件
  → 根据当前 hash 恢复对应视图与选中态
```

- 进入页面时若无 hash，默认重定向到 `#/dashboard`（数据看板）。
- 直接访问带 hash 的链接（如 `admin-dashboard.html#/records`）时，鉴权通过后直接进入对应视图。

## 6. 视图二：会话记录

### 6.1 视图内容

全平台用户会话列表表格：

| 列 | 字段 | 宽度 | 说明 |
|----|------|------|------|

## 7. 视图三：生图记录（核心视图）

### 7.1 视图内容

全平台图片生成记录明细表格，**完整展示以下 7 个字段**：

| 列 | 字段来源 | 宽度 | 说明 |
|----|----------|------|------|
| **用户名** | users.username | 120px | 对应生成图片的操作用户账号 |
| **会话名** | sessions.name | 160px | 图片所属的会话场景名称 |
| **生成时间** | generations.created_at | 150px | 图片创建的具体时间戳，格式 `YYYY-MM-DD HH:mm`，**精确到分钟** |
| **生图类型** | generations.gen_type | 110px | 分类标识，当前固定显示标签「**生成套图**」（对应值 `product_set`，为后续 AI 生图等类型预留扩展） |
| **套图类型** | generations.shot_type | 100px | 套图的具体分类标签：主图 / 场景 / 卖点（彩色标签，见 7.2） |
| **状态** | generations.status | 90px | 当前状态三态：**成功 / 进行中 / 失败**（映射规则见 7.3） |
| **缩略图** | generations.saved_path | 80px | 生成图片的缩略预览（48×48，圆角 6px），点击弹出大图 |

### 7.2 套图类型标签颜色

| 值 | 标签文字 | 背景色 | 文字色 |
|----|----------|--------|--------|
| main | 主图 | `#DBEAFE`（浅蓝） | `#1D4ED8` |
| scene | 场景 | `#D1FAE5`（浅绿） | `#047857` |
| selling | 卖点 | `#FEF3C7`（浅黄） | `#B45309` |

### 7.3 状态显示映射规则

| 数据库存储值 | 前端展示 | 颜色 |
|--------------|----------|------|
| success | 成功 | 绿色 `#10B981`（● 圆点 + 文字） |
| pending / generating | 进行中 | 蓝色 `#3B82F6'（● 圆点 + 文字） |
| failed | 失败 | 红色 `#EF4444`（● 圆点 + 文字） |

### 7.4 表格交互

- **默认排序**：按生成时间倒序（最新在前）
- **行悬停**：背景 `#F9FAFB`
- **缩略图点击**：弹出大图预览模态框（点击遮罩或 ✕ 关闭）；失败记录缩略图列显示 "-"
- **进行中状态**：行数据每 5s 轮询刷新一次，直至状态变为成功/失败
- **分页**：每页 20 条，分页控件「< 1 2 3 ... N >」

### 7.5 数据接口

- **GET /api/admin/records?page=N**
- 响应项字段：
  ```json
  {
    "username": "user1",
    "session_name": "无线耳机套图",
    "created_at": "2026-10-26 16:32",
    "gen_type": "product_set",
    "shot_type": "main",
    "status": "success",
    "image_url": "/uploads/gen_xxx.png"
  }
  ```
- 后端需 JOIN users / sessions 表获取用户名与会话名；`created_at` 由后端格式化为分钟级字符串返回。

## 9. 核心交互流程

### 9.1 页面加载

```
进入 admin-dashboard.html
  → 校验 localStorage token，无则跳转 admin.html
  → 解析 token 校验 role=admin，否则提示"无权限"并跳转
  → 读取 URL hash，无则默认 #/dashboard
  → 渲染顶部栏 + 侧边导航栏，设置对应菜单选中态
  → 加载目标视图数据：
    - dashboard → GET /api/admin/stats
    - sessions  → GET /api/admin/sessions?page=1
    - records   → GET /api/admin/records?page=1
    - feedback  → 无请求，直接渲染空状态
```

### 9.2 菜单切换

```
点击导航菜单项（如「生图记录」）
  → 更新 URL hash 为 #/records
  → 隐藏当前视图，显示生图记录视图
  → 更新导航选中态（左侧竖条 + 高亮）
  → 更新顶部栏视图标题为「生图记录」
  → 调用 GET /api/admin/records?page=1 渲染表格
```

### 9.3 翻页（会话记录 / 生图记录）

```
点击页码 N
  → 调用对应列表接口 ?page=N
  → 重新渲染表格
  → 更新分页控件当前页状态
```

### 9.4 缩略图预览（生图记录）

```
点击缩略图
  → 弹出模态框显示大图
  → 点击遮罩/关闭按钮关闭
```

### 9.5 登出

```
点击「登出」
  → 清除 localStorage token
  → 跳转 admin.html
```

## 10. 权限控制规则

| 层级 | 规则 |
|------|------|
| 页面访问 | 无 token → 强制跳转 `admin.html`；token 中 role ≠ admin → toast 提示"无权限"并跳转登录页 |
| 导航可见性 | 侧边导航栏仅管理员渲染，普通用户无任何入口进入该页面 |
| API 鉴权 | 所有 `/api/admin/*` 接口需携带有效 JWT，后端中间件校验 `role = 'admin'`，否则返回 403 |
| 数据范围 | 管理员可见**全平台所有用户**的统计数据、会话记录与生图记录（不做数据隔离） |
| 视图守卫 | 前端切换视图前重复校验 token 有效性，失效则跳转登录页 |

---

## 11. 异常处理

| 场景 | 处理 |
|------|------|
| 未登录访问 | 跳转 admin.html |
| 非管理员访问 | 提示"无权限"，跳转 admin.html |
| 统计接口失败 | 统计卡片数值显示 "—" |
| 列表接口失败 | 表格区域显示"加载失败，点击重试"（提供重试按钮） |
| 缩略图加载失败 | 显示灰色占位图 |
| 列表为空 | 显示空状态"暂无数据" |
| 未知 hash | 自动重定向到 `#/dashboard` |
