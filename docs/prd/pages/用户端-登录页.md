## 4. 核心功能

### 4.1 登录模式（默认）
- 输入用户名 + 密码
- 点击「登录」调用 `POST /api/auth/login`
- 成功：保存 token 到 localStorage，跳转 workspace.html
- 失败：显示错误提示（"用户名或密码错误"）

### 4.2 注册模式
- 点击「立即注册」切换到注册模式
- 按钮文字变为「注册」
- 调用 `POST /api/auth/register`
- 成功：自动登录并跳转工作台
- 失败：显示错误提示（如"用户名已存在"）

---

## 5. 交互流程

### 5.1 登录流程
```
输入用户名/密码 → 点击登录
  → 前端校验（非空）
    → 空：提示"请输入用户名和密码"
    → 非空：调用 API
      → 成功：存 token → 跳转 workspace.html
      → 失败：显示错误信息
```

### 5.2 注册流程
```
点击"立即注册" → 切换到注册模式
  → 输入用户名/密码
    → 密码 < 6 位：提示"密码至少 6 位"
    → 通过：调用注册 API
      → 成功：存 token → 跳转 workspace.html
      → 失败（用户名重复）：提示"用户名已存在"
```

---

## 6. 校验规则

| 字段 | 规则 | 提示 |
|------|------|------|
| 用户名 | 非空，3~20 字符 | "请输入用户名（3-20 字符）" |
| 密码 | 非空，≥ 6 字符 | "密码至少 6 位" |

## 7. 状态说明

| 状态 | 表现 |
|------|------|
| 初始 | 输入框为空，按钮可点击 |

| 失败 | 输入框红色边框，下方显示错误文字 |
