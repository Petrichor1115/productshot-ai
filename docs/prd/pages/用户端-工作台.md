# 子页面 PRD — 用户端工作台（v2.0 重构版）

> 所属产品：AI 商品套图生成器  
> 页面文件：`public/workspace.html`  
> 关联 JS：`public/js/workspace.js`  
> **变更摘要**：由 v1.2 单工作台重构为 **对话式首页 + 套图生成子页面** 双层 SPA 视图

---

## 1. 页面定位

用户端核心操作入口，承载两个互斥视图：

| 视图 | 参考图 | 定位 |
|------|--------|------|
| **对话式首页** | 参考图 1 | 用户登录后的默认落地页，统一 AI 交互入口，所有功能技能的分发中枢 |
| **套图生成子页面** | 参考图 2 | 点击「生成套图」后的专属操作页，专注于商品套图的参数配置和结果展示 |

视图切换通过 `workspace.js` 内部状态驱动，不做页面跳转。

## 5. 视图切换逻辑

### 5.1 触发条件
| 源 | 条件 | 目标视图 |
|----|------|----------|
| 对话式首页 | 点侧边栏「生成套图」技能按钮 | → 套图生成子页面 |
| 对话式首页 | 底部 Tab「生成套图」按钮 | → 套图生成子页面 |
| 对话式首页 | 输入卡 + 发送按钮（已上传图片） | → 套图生成子页面 |
| 对话式首页 | 点击已有会话项 | → 套图生成子页面（带数据） |
| 套图生成子页面 | 浏览器返回 | → 对话式首页 |

### 5.2 状态保持
- 视图切换时 **保留 localStorage 中的 token / user**，不重新鉴权
- 会话上下文（activeSessionId）跨视图保持
- 套图生成子页面返回首页时，输入卡保留当前上传的缩略图状态

## 6. 核心交互流程（v2.0 完整）

### 6.1 新建会话 → 套图生成
```
对话式首页 → 侧边栏「+ 新增会话」→ 输入名称 → POST /api/sessions
  → 自动选中新会话 → 输入卡上传图片（点虚线框 → POST /api/upload → 显示缩略图）
  → textarea 输入描述（可选）
  → 底部点「生成套图」pill
  → 自动进入套图生成子页面视图
  → 中列：自动回填上传的主图 + 预填会话补充信息
  → 用户调整：勾选组图类型、切换风格
  → 点「立即生成」
  → POST /api/generate(session_id, image_paths, supplement, shot_types, style)
  → 后端：豆包 C 2.1 分析 → 拼 prompt → Seedream 依次生成
  → 右列：大图预览区 loading → 成功后大图 + 底部缩略图列表
```

### 6.2 切换已有会话
```
对话式首页 → 点侧边栏历史会话项
  → GET /api/sessions/:id
  → 进入套图生成子页面视图
  → 中列回填：主图多图、补充信息、组图开关、风格选择
  → 右列恢复已生成结果（大图 + 缩略图 + 已生成 N 张用时 Xs）
```

### 6.3 四大暂不开通功能的行为
```
点侧边栏「AI 生图 / 爆款复刻 / 商品换色 / 风格裂变」
  → toast「该功能即将上线 ✨」
  → 不切换视图，保持当前页面
```

## 7. 异常处理

| 场景 | 处理 |
|------|------|
| 未登录访问 workspace.html | 自动跳转 `/index.html` |
| 会话列表加载失败 | 列表区显示红色错误提示 + 重试按钮 |
| 图片上传失败 | toast「上传失败，请检查网络」+ 清除缩略图 |
| 图片格式不对 | toast「请上传 JPG / PNG / WEBP 格式的图片」 |
| 图片超限（>10MB） | toast「图片大小不能超过 10MB」 |
| 生成时主图未上传 | 「立即生成」按钮 disabled，hover 提示「请先上传主图」 |
| 生成失败（后端异常） | 对应缩略图显示「生成失败」+ toast 错误信息 |
| 全部生成超时 | 整体超时提示 + 保留已成功的缩略图 |
| 网络断开 | 全局 toast「网络异常，请检查连接」 |
| token 过期 | 401 → 清除 token → 跳转登录页 |
